# 用户域战术建模文档

## 文件用途

本文档是LifeE系统用户域的核心设计参考文档，基于领域驱动设计（DDD）原则和事件风暴战略设计成果，为开发团队提供完整的战术建模指导。文档通过多个PlantUML图表，系统性地展示了用户域的聚合设计、CQRS模式应用和事件驱动架构实现。

## 概述

本文档集合基于事件风暴的战略设计，为LifeE系统的用户域提供了完整的DDD战术建模设计。通过多个PlantUML图表，详细展示了用户域的聚合设计、CQRS模式应用和事件驱动架构。

## 设计原则

### 1. 领域驱动设计（DDD）
- **聚合设计：** 以业务一致性为边界，确保数据完整性
- **值对象：** 不可变对象，封装业务规则和验证逻辑
- **领域服务：** 处理跨聚合的业务逻辑
- **领域事件：** 实现松耦合的跨域通信

### 2. CQRS模式
- **命令端：** 专注于业务逻辑执行和数据写入
- **查询端：** 优化读取性能，支持复杂查询
- **事件投影：** 保持读写模型的最终一致性

### 3. 事件驱动架构
- **异步处理：** 提高系统响应性能
- **松耦合：** 降低模块间依赖
- **可扩展性：** 支持新功能的灵活添加

## 核心业务规则

### 1. 用户注册规则
- 邮箱必须唯一
- 密码必须符合复杂度要求
- 新用户默认为待激活状态
- 自动创建用户资料和偏好设置

### 2. 用户认证规则
- 支持邮箱+密码登录
- 密码错误次数限制
- 账户锁定机制
- JWT令牌管理

### 3. 用户资料规则
- 昵称长度限制（最大50字符）
- 个人简介长度限制（最大500字符）
- 头像URL格式验证
- 偏好设置验证

### 4. 密码安全规则
- 最小长度8位，最大128位
- 必须包含大小写字母、数字和特殊字符
- 密码有效期90天
- 不能重复使用最近的密码

## 事件集成

### 1. 发布的事件
- **UserRegistered：** 用户注册完成
- **UserLoggedIn：** 用户登录成功
- **UserProfileUpdated：** 用户资料更新
- **UserStatusChanged：** 用户状态变更
- **PasswordChanged：** 密码修改

### 2. 跨域集成
- **知识库域：** 订阅UserRegistered创建默认知识库
- **推荐域：** 订阅用户行为事件进行个性化推荐
- **通知域：** 订阅状态变更事件发送通知
- **统计域：** 订阅所有用户事件进行数据分析
